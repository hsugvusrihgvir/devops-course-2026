### Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?

В Git ветка это указатель на определённый коммит, поэтому создание новой ветки происходит быстро и не требует копирования всего проекта. Переключение между ветками также выполняется локально.

В SVN ветки это отдельные директории в репозитории. Многие операции связаны с центральным сервером, а переключение между ветками может занимать больше времени. 

Поэтому Git лучше подходит для частого создания и использования веток.

### Можно ли в SVN сделать коммит без интернета? Почему?

Нет, если репозиторий находится на удалённом сервере. SVN - централизованная система контроля версий. Команда svn commit сразу отправляет изменения в центральный репозиторий, поэтому для неё требуется соединение с сервером.

В Git репозиторий есть локально у каждого разработчика, поэтому git commit можно выполнять без подключения к сети. Интернет понадобится уже для отправки изменений в удалённый репозиторий.

### В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN может быть удобнее там, где нужна простая централизованная модель работы и строгий контроль над единым репозиторием. Также SVN может использоваться в проектах с большим количеством бинарных файлов и в старых корпоративных проектах, где инфраструктура и процессы уже построены вокруг SVN.
